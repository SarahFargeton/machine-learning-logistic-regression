# Logistic Regression Learning Project

<br>

## Overview

<br>

This project was completed as part of an introductory Artificial Intelligence course in Biotechnology Engineering at ESTBB.

<br>

The aim of this project was to learn how a classification model is developed using logistic regression. Rather than focusing on obtaining the best predictive performance, the objective was to understand the complete workflow of a supervised machine learning project, from data exploration and preprocessing to model evaluation.

The project uses a breast cancer diagnosis dataset containing morphological characteristics extracted from medical images of breast tumors. The goal is to predict whether a tumor is benign or malignant based on these features.

<br>

## Learning Objectives

<br>

- Import and explore a real-world medical dataset
- Perform descriptive statistical analysis
- Detect and handle missing values
- Compute and interpret a correlation matrix
- Separate features and target variables
- Encode categorical labels using numerical values
- Normalize numerical features
- Split the dataset into training and testing sets
- Build a logistic regression classification model using Scikit-learn
- Generate predictions on unseen data
- Evaluate model performance using classification metrics
- Interpret a confusion matrix and classification results

<br>

## Dataset

<br>

The project uses the Breast Cancer Wisconsin Diagnostic Dataset, containing features computed from digitized images of fine needle aspirates of breast masses.

Each observation corresponds to a breast tumor characterized by several numerical features describing cell nuclei properties such as:

- Radius
- Texture
- Perimeter
- Area
- Smoothness
- Compactness
- Concavity

The target variable is:

- **Diagnosis**
  - M = Malignant tumor
  - B = Benign tumor

The dataset contains 569 observations and 30 predictive features.
